Software Development Portfolio

Project Proposal

Website Purpose

The purpose of my website is to create a professional portfolio that showcases my education, programming skills, projects, and career goals. I am currently studying Computer Programming and Analysis at Broward College. My goal is to begin my career in IT support and eventually transition into software development.

Target Audience

My target audience includes employers, recruiters, hiring managers, and technology professionals. The website will help them understand my education, technical skills, qualifications, and career interests.

Portfolio Components

  • Home: Introduction and career goals
  • Projects: Programming assignments
  • Skills: Technical skills and abilities
  • Resume: Education and work experience
  • Contact: Professional contact information

Technical Planning

HTML5 will provide the website structure. CSS3 will control the layout and appearance. JavaScript will support interactive features. Responsive design will allow the website to work on desktop and mobile devices. GitHub Pages will be used for hosting.

Research Sources

MDN Web Docs provides guidance about HTML, CSS, JavaScript, and responsive web design. W3C provides standards and validation resources for creating reliable websites.

  • MDN Web Docs
  • W3C Web Accessibility Initiative
